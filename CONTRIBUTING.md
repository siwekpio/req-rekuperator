# Wkład w projekt / Contributing

Zgłaszaj błędy i propozycje przez GitHub Issues. Przed większą zmianą uzgodnij zakres. Nie przesyłaj danych dostępowych ani nieuprawnionych fragmentów cudzego kodu. Testuj na symulatorze lub izolowanym środowisku, nie na cudzym urządzeniu. Przekazując wkład do kodu lub dokumentacji, potwierdzasz, że masz prawo udostępnić go na GPL-3.0-only. Nie wymagamy przeniesienia praw autorskich.

Please discuss substantial changes first. Submit only contributions you have the right to license under GPL-3.0-only; no copyright assignment is required. Never include credentials or unauthorized third-party code. Test against mocks or isolated systems. See [SECURITY.md](SECURITY.md) for vulnerability reporting.
