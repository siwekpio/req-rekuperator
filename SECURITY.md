# Zgłaszanie podatności / Reporting vulnerabilities

Jeżeli zauważysz problem bezpieczeństwa integracji Rekuperator reQ, **nie umieszczaj w publicznym Issue** haseł MQTT, tokenów Home Assistant, adresów IP/MAC urządzeń ani gotowych szczegółów umożliwiających wykorzystanie błędu.

Zgłoś problem właścicielowi `@siwekpio` prywatnie, korzystając z funkcji **Report a vulnerability** / GitHub Private Vulnerability Reporting, o ile jest włączona dla tego repozytorium. Jeśli nie jest dostępna, najpierw poproś opiekuna o bezpieczny kanał kontaktu, nie publikując szczegółów podatności.

Podaj: wersję integracji i HA, krótki opis skutków, kroki reprodukcji w środowisku testowym oraz informację, czy skutki potwierdzono na fizycznym urządzeniu. Nie załączaj sekretów.

**English:** Please use GitHub Private Vulnerability Reporting if available, or request a private contact channel. Do not post credentials, real device identifiers, or exploit details publicly.
