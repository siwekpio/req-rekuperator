# Rekuperator reQ v0.1.12

Pierwsze wydanie na licencji GPL v3. Monitoruj i steruj rekuperatorem REQNET w Home Assistant, korzystając z MQTT, panelu i wykresów historii.

- Odczyt aktualnej nastawy komfortu i odporność na nieprawidłowe dane MQTT.
- Panel sterowania, wykresy, diagnostyka połączenia i informacje o urządzeniu.
- Instrukcja instalacji i konfiguracji MQTT po polsku i angielsku.

Przed instalacją lub aktualizacją wykonaj kopię zapasową HA. Zobacz [README](README.md). Zgodność wszystkich modeli nie została potwierdzona. Czysta instalacja integracji na istniejącym HAOS (symulowane MQTT) oraz cykl powrotu do 0.1.11 i ponownej aktualizacji do 0.1.12 zostały sprawdzone odczytowo w środowisku testowym.

**English:** First GPL v3 release: REQNET monitoring and control via MQTT, dashboard, history charts and diagnostics. See [English README](README.en.md) for installation. Back up HA first. Compatibility across all models has not been established. A clean integration installation on an existing HAOS system (simulated MQTT), rollback to 0.1.11 and re-upgrade to 0.1.12 passed read-only functional checks in a test environment.
